## 1. Purpose and Scope
This document provides the Software Requirements Specification (SRS) and Functional Requirements Specification (FRS) for `SetuHaul_Rescheduling_Service`, detailing functional requirements (`FR-01`–`FR-15`), non-functional requirements (`NFR-01`–`NFR-07`), and external interface requirements.

## 2. Executive Summary
The system delivers 15 verified functional requirement areas covering multilingual conversational rescheduling, deterministic ETA/feasibility, concurrency-safe holds/confirmations, warehouse dock/exception management, facility changes, partner email bookings, Dock Access Passes & gate security, multi-mode authentication, RBAC, runtime configuration, audit logging, and opt-in retention (`[Verified]`). Non-functional verification is strong on local concurrency/integrity (`100/100` contention runs, `0` invariant violations) but incomplete on live LLM behavior, real external IdP/SMTP/Telegram/Redis integrations, and regulatory compliance (`[Unverified]` / `[Missing]`).

## 4. Non-Functional Requirements Specification (NFR)

| ID | Category | Specification | Current Status & Evidence |
|---|---|---|---|
| `NFR-01` | Concurrency & Integrity | Zero double-booked slots; 12 SQL integrity invariants + FK check hold under concurrent writers (`BEGIN IMMEDIATE`, WAL, `5000ms` busy timeout). | `[Verified]` locally (`docs/verification/concurrency-proof.md:3-127`, 100/100 runs, 0 violations). |
| `NFR-02` | Performance & Scalability | Capacity search p99 $< 500\text{ ms}$ (measured `13.4 ms` on 826 slots); single-writer SQLite saturates at `~244 holds/s` (p99 `4.2s` at 16 writers). | `[Verified]` with stub model; `[Unverified]` under real LLM latency (`docs/verification/scale-test.md:3-53`). |
| `NFR-03` | AI Safety & Bounds | Hard caps outside LangGraph: `6` rounds, `4` tool executions, `8s` call timeout, `1` retry, `30s` deadline, `800` output tokens, `$0.05` cost stop; prompt canary + claim guards. | `[Verified]` in deterministic/scripted tests; `[Unverified]` against live LLMs (`docs/readiness-detail.md:10,31`). |
| `NFR-04` | Security & Confidentiality | Server-side RBAC, HMAC-SHA256 webhooks, `scrypt` passwords, Fernet secret encryption, SameSite=Lax + same-origin CSRF, HTML CSP, append-only audit log. | `[Verified]` with known hardening gaps (`TD-07`, `TD-11`, `RSK-07`). |
